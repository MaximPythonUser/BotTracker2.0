# 🏋️ Training Tracker Bot — Бот, который не ошибается

Простой трекер тренировок, где упор сделан на удобство пользователя и защиту от ошибок. В отличие от многих учебных ботов, здесь реализован не просто набор команд, а продуманный пользовательский путь (User Flow).

## ✨ В чем фишка?

Я спроектировал бота так, чтобы минимизировать когнитивную нагрузку на пользователя и исключить ввод некорректных данных.

*   **Персонализированное общение:** Бот всегда приветствует пользователя по имени, взятому из профиля Telegram (`first_name`). Это маленькая деталь, которая сильно повышает вовлеченность: пользователь чувствует, что бот «знает» его.
*   **Гибридный ввод:** Команда `/edit` показывает список тренировок с кнопками. Пользователь не должен помнить ID записи или вводить сложные команды. Он просто нажимает «Изменить дату», и бот сам подсказывает, что писать дальше.
*   **Защита от мусора:** Бот жестко валидирует формат даты (`YYYY-MM-DD`) и времени (`HH:MM`). Если пользователь напишет «завтра» или «семь вечера», бот вежливо попросит исправить формат, а не сохранит ошибку в базу.
*   **Контекстная помощь:** Команда `/start` дает не просто приветствие, а краткую справку с примерами, чтобы пользователь сразу понял синтаксис.

## 🧱 Технологии

*   **aiogram 3.x:** Современный стандарт для Telegram-ботов на Python.
*   **aiosqlite:** Позволяет работать с базой данных без блокировки работы бота.
*   **python-dotenv:** Безопасное хранение секретов.

## 📂 Структура данных

Данные хранятся в SQLite. Ключевое поле — `user_id`. Это позволяет масштабировать решение: сегодня бот работает для одного человека, завтра — для тысячи, и данные не перемешаются.

## 📋 Функционал

*   `/add` — добавить тренировку.
*   `/my_trainings` — посмотреть список.
*   `/edit` — отредактировать конкретную деталь (только дату ИЛИ только время).
*   `/delete` — удалить по номеру из списка.
